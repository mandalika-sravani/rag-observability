# AcmeCloud Pricing

AcmeCloud has three plans: Free, Pro and Enterprise.

The Free plan includes 1,000 API requests per day and 1 GB of storage. It is meant for hobby projects and has community-only support.

The Pro plan costs $29 per month and includes 100,000 API requests per day, 50 GB of storage and email support with a 24-hour response time.

The Enterprise plan has custom pricing. It includes unlimited API requests, a dedicated account manager and a 99.99% uptime SLA.

Annual billing gives a 20% discount on the Pro plan.
