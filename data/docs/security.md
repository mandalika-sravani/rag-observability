# AcmeCloud Security

All data is encrypted at rest with AES-256 and in transit with TLS 1.3.

AcmeCloud supports two-factor authentication (2FA) using authenticator apps or hardware security keys. Enterprise accounts can enforce single sign-on (SSO) with SAML.

Data is stored in three regions: us-east-1, eu-central-1 and ap-south-1. Customers choose their region when creating a project, and the region cannot be changed later.

AcmeCloud is SOC 2 Type II certified and runs a public bug bounty program.
